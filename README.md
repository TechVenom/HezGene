# 🧬 HezGene — The DNA of Software

**Autonomous genetic software evolution. Code that improves itself.**

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)

## Quick Start

```bash
pip install hezgene
hezgene init
hezgene run src/
```

Everything is free. Everything is open source. MIT License.

## Features

- 🧬 6 AST mutation strategies
- 🤖 LLM-powered mutations (Ollama, OpenAI, Anthropic, Gemini, VENOMX)
- 🏟️ 5-Ring Fitness Gauntlet
- 📊 DNA tracking and evolution history
- 🖥️ Battle Arena Web Dashboard
- 🔧 CI/CD integration
- 🛡️ Automatic rollback and verification
